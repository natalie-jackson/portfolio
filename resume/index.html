Signal Match · Designed and built

A production AI system that matched customer feedback to existing issues and shipped releases, so the field knew when a request was already being worked on or had shipped.

The problem
Across a repository of 12,000+ issues, nobody could reliably tell whether a new customer request duplicated something already tracked, or whether a release had just solved it.
What I did
  • Designed semantic matching on Azure AI Search with GitHub Models / Azure OpenAI, using MCP for tool access.
  • Built it safety-first: human-in-the-loop review, validation, and confidence scoring, so no match reached a customer-facing team unreviewed.
  • Defined the routing logic, review workflow, and quality guardrails, and iterated the instructions and matching rules from real usage.
  • Worked through three architectural pivots to eliminate hallucinated matches.
Outcome
6,000+ issues processed live in production, closing the loop between launches and roadmap prioritization.
