# Natalie Rodriguez-Jackson

**[natalierodriguezjackson.com](https://natalierodriguezjackson.com)**

My personal site: who I am, the work I've done, and what I'm building right now.

I'm a program and product operations leader who gets GTM, product, and engineering moving as one. I started in support, learned to write the code, and most recently ran AI programs for Copilot at GitHub.

## Built with

- Plain HTML, CSS, and JavaScript. No frameworks, no build step.
- Hosted on GitHub Pages with a custom domain.
- Built and maintained with Claude Code.

## Run it locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Updating the site

Every push to `main` goes live in a minute or two. To add a project, I copy `writing/_template.html`, write the post, and add it to `assets/js/posts.js`.
